# LLM interactions

The course asks for your first five interactions with an LLM about this project to be kept here.

Save each one as its own file, copied from your real chat history, for example:

- `01-project-idea.md`
- `02-architecture.md`
- `03-critical-path-logic.md`
- `04-ui-graph.md`
- `05-tests-and-readme.md`

Paste the prompt you typed and the answer you got. Do not write these from memory or invent them.
